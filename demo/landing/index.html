Eleven directions

Eleven portfolio sites, one set of facts.

Each one is a complete site — hero, selected work with the real screenshots, experience, skills, about, contact — built against a different reference point rather than a different colour scheme. The content is deliberately consistent so the art direction is what you’re actually comparing.

Every fact comes from the résumé PDF: three roles, two projects, the exact skill groupings, both degrees. The only number claimed anywhere is the ~40% onboarding reduction, because it’s the only one on the résumé. All eleven use the real pragnyapan-ai.jpg and meet-space.jpg screenshots, the real profile photo, and the real tech icons from public/.

What’s the same in all eleven

  • Facts — three roles with real dates and locations, two projects, six skill groups, two degrees with grades. Nothing invented, including the numbers behind K’s charts.
  • Assets — the tall pragnyapan-ai.jpg capture scrolls on hover (or on scroll, in E), meet-space.jpg is cropped to its top, and the real tech SVGs are used throughout.
  • Behaviour — keyboard-reachable links with visible focus, prefers-reduced-motion respected, content still readable with JavaScript off, and no framework or build step. Eleven standalone HTML files.
  • Switcher — the pill at the bottom of every page jumps straight between directions, so you can compare the same section side by side.
