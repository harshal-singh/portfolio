Hero animation variations

Three pure HTML/CSS demos. Open each file directly in the browser — no build step. Pick one to port into components/sections/Hero.tsx.

Variation A

Cascade stagger

Sequential fade-up: label → headline → highlight underline draw → body → CTAs → meta. Closest to production default.

 Variation B

Split words + orbit

Headline words reveal one-by-one; floating tech pills orbit on the right. More expressive, still subtle.

 Variation C

Ambient glow

Slow gradient drift + unified content fade; live metric strip animates in at the bottom. Premium/minimal.
Production site uses Variation B (split words + orbit) in Hero.tsx + scroll Reveal on sections.
